# Security policy

## Reporting a vulnerability

The repository is private, so GitHub private vulnerability reporting is unavailable. Until it
goes public, report vulnerabilities privately to the maintainer `@abj360` on GitHub, by direct
message or through the private repository collaborator channel. Once the repository is public,
use private vulnerability reporting: open the Security tab and choose "Report a vulnerability".
Never open a public issue or pull request for a security problem.

## Scope

The latest tagged release and `main` receive fixes.
