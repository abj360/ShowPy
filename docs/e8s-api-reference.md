# e8Show Library: API Reference

Nov 11, 2026 · @Peter

Last updated: 2026-11-23

## How to read this reference

This is the complete API of `e8s`, the choreography library behind the Show Canvas (2D sheet; the 3D layer has its own reference), listed module by module: every data class with its fields, and every function with its inputs, output and purpose. Spots are the dots designed on the sheet.

The first build covers every module except the consumer checker (below), `e8s.packs` and `e8s.index`; their sections describe the planned design. Where this reference and the code disagree, the code and the ADRs in `docs/adr/` win; ADR 0001 lists the fixes made to the 2026-11-08 version of this document.

**Conventions used in every table**

- Distances are meters on the 2D stage plane (x audience-left to audience-right, y away from the audience); 3D world is Y-up, glTF axes.
- Origin: `(0, 0)` is the front-center of the sheet. x runs from −width/2 to +width/2 and y from 0 (the audience edge) to depth. The mirror line `x = 0` is the center line.
- Facing is degrees, 0 = toward the audience, counter-clockwise positive seen from above. The facing vector is `facing_vector(θ) = (sin θ, −cos θ)`: 0° points to −y, 90° to +x. Under any linear map `M` a facing becomes `vector_facing(M · facing_vector(θ))`, which covers rotate, mirror, scale and skew.
- Time is `Count` (musical pulse), `Seconds`, or measures; a transition's local time is `tau`, from 0 to its counts. Global count 0 is the show start and maps to 0 seconds; an audio track's `sync_offset_s` is the audio time at count 0. Measure and count labels for display are 1-based.
- All data classes are frozen Pydantic v2 models with JSON schemas. Stored geometry is JSON-safe: models hold `Point` tuples, `Ring`s and `Region`s, never NumPy arrays or Shapely objects; functions accept and return `Points` and Shapely polygons.
- Functions are pure: "edit" functions return a new object, and functions that edit pinned or locked items raise `LockedError` unless the caller passes `force=True`. Storage writes (`DocumentRepository.put_*`, `transaction`) check that the data is valid and never check pins or locks; the edit functions enforce pins and locks for every caller. Builders that take a spec (`two_part`, `set_style`, `rotate_path`) guard the spec they receive; a stored change is re-checked against the stored show when it is committed. e8Show has no principals: permissions, authorship and commit messages belong to the host application. The library never reads the clock: every time stamp is an explicit `at: datetime` argument. Stores and services (`SheetStore`, `Repository`, `AssetStore`) are injected, and registries are immutable: registering returns a new registry.
- `Points` = NumPy array of shape (N, 2), float64. `Selector` = selection expression, list of IDs, or `Selection`.
- `import e8s` re-exports the public API lazily (PEP 562): a name is imported on first use, e.g. `e8s.line`. Internal helper modules (engine compilation, matching cost and solver internals, workspace documents) are not re-exported. One name clashes and is renamed: the motion function `spiral` is `e8s.spiral_motion`; `e8s.spiral` is the geometric spiral curve. Subpackage `__init__` files hold only a docstring, and library code imports from the submodule, e.g. `from e8s.geo.shapes import line`.
- `e8s.examples` holds small, deterministic example shows for docs, doctests and tests: `field_sheet()`, `two_set_show()`, `with_rows(rows, routes=None, show=None)`, `with_targets(updates, show=None)`, `crossing_show()`, plus `EXAMPLE_TIME` and `EXAMPLE_TID`. `field_sheet()` is a plain 40 × 20 m blank sheet.
- Installing e8s from a GitHub release (the attached wheel, or `uv add "e8s @ git+https://github.com/abj360/e8s@<tag>"`; it is not on PyPI) installs numpy, scipy, shapely and pydantic only. pandas is the extra `tables` (`all` holds it too); a function marked "needs the `<name>` extra" raises `MissingExtraError` at call time without it.
- `→ X` means the function returns X. Optional arguments show their defaults. A `*` in a signature starts the keyword-only arguments; every boolean flag (`force`, `keep_end`, `include_hidden`, ...) is keyword-only. Two families leave shared trailing arguments out of their table rows: the transforms of `e8s.choreo.set_transforms` and `e8s.choreo.set_snapping` all end in `sel="all", *, force=False`, and the path editors of `e8s.choreo.paths` (all but `default_paths`, `lock`, `unlock` and `paths_table`) end in `*, force=False`; `curve_path(spec, entity, *control, force=False)` takes it after its control points.
- The library has no users yet, so it keeps no deprecation warnings: a name that a later release replaces is current API until then, and the replacing release changes it directly.

### e8s.core.selection

**`Selection`** — ordered, duplicate-free `ids: tuple[SpotId, ...]` plus `description: str`; supports `|`, `&`, `-`, `len` and `in`. Iterate `sel.ids`: a `Selection` is not iterable by ID. Two selections are equal when their IDs are, whatever their descriptions. The operators take another `Selection` or any iterable of IDs and refuse a bare string with `SchemaError`. `e8s.cast.select` re-exports it.

| Name            | Definition                            | Represents                                                          |
| --------------- | ------------------------------------- | ------------------------------------------------------------------- |
| `Selector`      | `str \| Sequence[str] \| Selection`   | Who an operation applies to                                         |
| `SelectorField` | `str \| tuple[str, ...] \| Selection` | The JSON-safe selector stored on models (`FacingOverride.entities`) |

### e8s.core.ids

| Name                | Format                                                        | Represents                                         |
| ------------------- | ------------------------------------------------------------- | -------------------------------------------------- |
| `SheetRef`          | `str`, written `sheet:<id>@<version>`                         | A sheet template or saved sheet; defined only here |
| `SpotId`            | checked ID, e.g. `T4`, `flag_12`                              | Spots in a show                                    |
| `SetId`             | checked ID, e.g. `12`, `12A`                                  | A set in a show                                    |
| `TransitionId`      | `NamedTuple(from_set: SetId, to_set: SetId)`, written `12→13` | Movement between two sets                          |
| `FormId`, `RouteId` | checked ID                                                    | Named items                                        |

The ID aliases are `NewType`s of `str`: public functions accept plain `str` (and `tuple[str, str]` for a transition), while model fields and return values carry the NewTypes. A checked ID matches `ID_PATTERN` (letters, digits, `_` and `.`, at most `ID_MAX_LENGTH` characters, no leading or trailing `.`, no reserved name) and is stored NFC-normalized; sheet references, sheet items and show IDs follow `SHEET_ID_PATTERN`, which also allows an inner `-`. A `TransitionId` still equals, hashes, unpacks and serializes like the pair `("12", "13")`.

| Function                                                    | Inputs                  | Output                        | Purpose                                                                                                                       |
| ----------------------------------------------------------- | ----------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `parse_ref(text)`                                           | `str`                   | `(kind, id, version \| None)` | Read a reference such as `sheet:hs-football@1`; the id and version must pass `check_sheet_id`                                 |
| `format_ref(kind, ref_id, version=None)`                    |                         | `str`                         | Write one                                                                                                                     |
| `make_tid(from_set, to_set)`                                | two set IDs             | `TransitionId`                | Check both IDs with `check_id` and pair them                                                                                  |
| `parse_tid(text)`                                           | `"12→13"` or `"12->13"` | `TransitionId`                | Read a transition ID; both parts must pass `check_id`                                                                         |
| `format_tid(tid)`                                           | `TransitionId`          | `str`                         | Write one as `12→13`; anything but a pair raises `SchemaError`                                                                |
| `check_id(text, *, kind)` / `check_sheet_id(text, *, kind)` | `str`                   | `str`                         | Validate one ID (sheet IDs may hold an inner `-`) and return its NFC-normalized text; raise `SchemaError` naming the position |

| `units()`                                                    |                                | `dict[str, float]`        | List the default units                                                                                                                  |
| `normalize_angle(deg)`                                       | `Degrees`                      | `Degrees` in \[0, 360)    | Wrap an angle (defined in `e8s.core.numbers`); refuses NaN and infinity, never returns −0.0                                             |
| `angle_diff(a, b)`                                           | `Degrees`, `Degrees`           | `Degrees` in (−180, 180\] | Signed shortest turn                                                                                                                    |
| `facing_vector(theta)`                                       | `Degrees`                      | unit `Point`              | Facing to direction, `(sin θ, −cos θ)`; 0° → (0, −1)                                                                                    |
| `vector_facing(v)`                                           | `Point`                        | `Degrees` in \[0, 360)    | Direction to facing; raises `ZeroLengthError` on (0, 0)                                                                                 |

### e8s.core.errors

Every error has `code: ErrorCode`, `message: str`, `context: dict`, `hint: str`, and is raised as `E8sError(message, *, hint, context=None, code=None)`; `code` defaults to the class's own code (`UNKNOWN_REF`, `LOCKED`, ...). `str(error)` reads `CODE: message (hint: ...)`, and `to_dict()` returns the error as JSON. The context is bounded on construction: text and reprs are cut to 80 characters around a `…`, sequences keep 20 items plus a `(+n more)` count, and numpy values become plain numbers.

`ErrorCode` (`e8s.core.error_codes`) is a `StrEnum` catalogue of every code the library raises or reports; its values equal its names, and `docs/error-codes.md` lists each code with the classes that raise it.

| Class                 | Parent          | Raised when                                                                                      |
| --------------------- | --------------- | ------------------------------------------------------------------------------------------------ |
| `E8sError`            | `Exception`     | Base of all library errors                                                                       |
| `UnknownRefError`     | `E8sError`      | An ID, name or unit does not resolve; hint lists close matches                                   |
| `VersionError`        | `E8sError`      | A pinned version is missing or incompatible                                                      |
| `SchemaError`         | `E8sError`      | Data fails its JSON schema or text format; names the field                                       |
| `GeometryError`       | `E8sError`      | Degenerate shape (zero radius, open polygon, collinear arc points)                               |
| `ZeroLengthError`     | `GeometryError` | Direction of a zero vector requested                                                             |
| `SpacingError`        | `E8sError`      | Items do not fit; reports the maximum that fits                                                  |
| `TimeRangeError`      | `E8sError`      | Times outside range or start ≥ end                                                               |
| `TimelineError`       | `E8sError`      | Inconsistent tempo, measure or hold data                                                         |
| `SurfaceError`        | `E8sError`      | A point is off the sheet                                                                         |
| `MatchError`          | `E8sError`      | No feasible assignment; names the blocking constraint                                            |
| `PathError`           | `E8sError`      | Invalid path instruction                                                                         |
| `ContinuityError`     | `PathError`     | A path does not end on its target placement                                                      |
| `LockedError`         | `E8sError`      | Edit touches something the designer locked                                                       |
| `StorageError`        | `E8sError`      | Persistence failure                                                                              |
| `ConflictError`       | `StorageError`  | A concurrent edit landed first; lists what changed                                               |
| `ShowValidationError` | `E8sError`      | Structural integrity failure; `ValidationReport.raise_for_errors()` raises it                    |
| `MissingExtraError`   | `E8sError`      | A function needs an extra that is not installed; hint is the install command (`e8s.core.extras`) |

A raise site may pass its own `code`; the class still says which family it belongs to. The text codes are listed under "Text error codes".

| Code              | Class               | Raised when                                                                                                                        |
| ----------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |

| `BAD_PATH`        | `StorageError`      | A show ID, workspace path or stored path cannot be stored: unknown root, `.`, `..`, empty part, a directory, a Windows device name |

| `PROPOSAL_CLOSED` | `SchemaError`       | A proposal that is already accepted or rejected is accepted or rejected again                                                      |
| `STALE_FORM`      | `E8sError`          | A form's set no longer places that form; re-place the set with the form or delete the form                                         |
| `SEGMENT_BOUND`   | `PathError`         | A segment stays over the tolerance after the maximum number of splits; the hint gives a `tol` that passes                          |
| `BAD_SHAPE`       | `GeometryError`     | `similarity_fit` gets arrays that are not numeric and `(N, 2)` of equal shape                                                      |
| `TOO_FEW_POINTS`  | `GeometryError`     | `similarity_fit` gets fewer than two landmarks                                                                                     |
| `NOT_FINITE`      | `GeometryError`     | `similarity_fit` gets NaN or infinite coordinates                                                                                  |
| `DEGENERATE`      | `GeometryError`     | `similarity_fit` gets landmarks that sit on top of each other                                                                      |
| `REFLECTION`      | `GeometryError`     | `similarity_fit` gets landmarks that are mirrored between the two sheets                                                           |
| `NAME_TAKEN`      | `SchemaError`       | `define_selection` names a selection that already exists and `replace` is false                                                    |
| `MIXED_OPERATORS` | `SchemaError`       | A selector mixes `&` with `+` or `-` at one parenthesis level without parentheses                                                  |
| `RANGE_PADDING`   | `SchemaError`       | A range's endpoints are spelled with different zero-padding, such as `T1-T010`                                                     |
| `STRICT_JSON`     | `SchemaError`       | Stored or imported JSON holds NaN, infinity, a repeated key, a byte-order mark or a lone surrogate                                 |
| `UNKNOWN_FORMAT`  | `SchemaError`       | A show.json or interchange document names no known format, or half a format header                                                 |
| `OLD_FORMAT`      | `SchemaError`       | A commit or workspace write would store a show.json of an older format version                                                     |
| `RESERVED_MOTION` | `PathError`         | A motion registry would bind `weave`, `zigzag`, `figure_eight` or `spiral` to another function                                     |
| `MISSING_EXTRA`   | `MissingExtraError` | A function needs an optional dependency whose extra is not installed                                                               |

Models raise `SchemaError`, never pydantic's `ValidationError`: its context lists at most five failing fields, each input cut to 80 characters (`bounded_repr`, which never raises on size and echoes ints of 640 or more digits as their bit count). `field_errors(error)` returns a converted error's per-field list and re-raises an error that has none. A value outside a named bound gets a hint that names the bound and its constant, e.g. `keep each value between -1,000,000 and 1,000,000 m (MAX_COORD_M)`. `ValidationReport` issues carry their own codes (`UNKNOWN_SPOT`, `PINNED_CHANGED`, ...) and are not errors.

### e8s.core.caps

Output sizes are checked before anything is allocated; `require_size(requested, cap, *, what, error=SchemaError)` raises when a size is negative or over its cap. Caps are `MAX_POINTS` (1,000,000), `MAX_TABLE` (1,000,000), `MAX_GRID_CELLS` (4,000,000), `MAX_RANGE` (10,000), `MAX_DEPTH` (64), and `MAX_TEXT_CHARS` (1,000,000). Stored values are bounded by `MAX_COORD_M` (1e6 m, for `Meters` and points), `MAX_COUNTS` (1,000,000 counts) and `MIN_TEMPO` (1e-3 counts per minute); a value past them raises `SchemaError` instead of becoming NaN or infinity later. `MIN_LAYOUT_HEIGHT_M` (1e-3 m) is the smallest text height `layout_text` accepts.

## e8s.cast

Who is in a show: groups, spots, labeling rules, named selections, and the selection language used everywhere to pick them.

### e8s.cast.models

**`Group`** — a designer-made set of spots with shared defaults.

| Field             | Type                  | Default             | Meaning                                                |
| ----------------- | --------------------- | ------------------- | ------------------------------------------------------ |
| `key`             | `str`                 | required            | e.g. `trumpets`, `front-guard`                         |
| `name`            | `str`                 | key in title case   | Display name                                           |
| `label_prefix`    | `str`                 | required            | e.g. `T` gives T1, T2                                  |
| `symbol`, `color` | `str`                 | `circle`, `#808080` | 2D sheet glyph and `#rrggbb` color                     |
| `default_radius`  | `Meters`              | 0.3                 | Footprint radius for new spots; positive and finite    |
| `limits`          | `Mapping[str, float]` | {}                  | Per-group limit overrides (see the checker); read-only |
| `moves`           | `bool`                | True                | False for stationary groups (pit)                      |

**`Spot`** — a dot designed on the sheet that persists through the whole show.

| Field             | Type              | Default           | Meaning                                                                                    |
| ----------------- | ----------------- | ----------------- | ------------------------------------------------------------------------------------------ |
| `id`              | `SpotId`          | required          | Label shown on the sheet, stable all show; a checked ID                                    |
| `group`           | `str`             | required          | Group key                                                                                  |
| `symbol`, `color` | `str \| None`     | None (from group) | Sheet display; a color is `#rrggbb`                                                        |
| `tags`            | `tuple[str, ...]` | ()                | e.g. `soloist`, `leader`; deduplicated in first-seen order                                 |

### e8s.cast.select

**`Selection`** is re-exported from `e8s.core.selection`.

Expression grammar for `select`: IDs `T4`, ranges `T1-T8`, prefixes `T*` (labels whose prefix before the trailing number is exactly `T`), `all`, `group:trumpets`, `form:arc1`, `tag:soloist`, `shape:rectangle`, `sel:<name>` (a named selection), combined with `+` (union), `-` (difference), `&` (intersection) and parentheses. `+` and `-` apply left to right (`T* + B* - T3` is `(T* + B*) - T3`); `&` chains with itself (`tag:a & T* & front`), but mixing `&` with `+` or `-` at one parenthesis level raises `SchemaError` (code `MIXED_OPERATORS`) whose hint shows both parenthesized readings. Operators need spaces or parentheses on both sides (`T1 + T2 - T3`, `(T*)-(T2)`); a glued operator such as `T1+T2` raises `SchemaError` with its position, because `T1-T8` without spaces is a range. A `Set` cannot resolve `group`, `tag`, `shape` or `sel` words; a `Cast` cannot resolve `form` words.

## e8s.geo

The drawing toolkit on the stage plane: curves and regions, spots spaced along or inside them, transforms that move whole shapes, and static measurements. `e8s.geo` imports only `e8s.core` and itself: its transforms and measurements take `Points` or a curve. The same transforms taking a `Set` with a selector, and the measures and design feedback that read a `Set` or `Sheet`, live in `e8s.choreo.set_transforms`, `set_snapping`, `set_measure` and `set_analysis`, and the top-level `e8s.<name>` resolves to those. Forms go through `e8s.choreo.form_ops.transform_form`. Measures over time live in `e8s.choreo.motion_stats`.

### e8s.geo.curves (with shapes, regions, svg, text, affine)

The `Curve` protocol is in `e8s.geo.curve_base`, the curve models in `e8s.geo.curves`, constructors in `e8s.geo.shapes`, area operations in `e8s.geo.regions`, SVG path parsing in `e8s.geo.svg`, the built-in stroke font in `e8s.geo.text`, and affine matrices in `e8s.geo.affine`. ### Text layout and fonts (`e8s.geo.text_layout`, `e8s.geo.fonts`)

Text is drawn with single-line stroke fonts: each glyph is a set of strokes, not an outline. Five fonts ship in `e8s/fonts/` (`importlib.resources`): `relief-singleline` (423 glyphs, Latin, Latin-1, Latin Extended-A, Greek smalls), `hershey-roman` (95), `hershey-script` (95), `hershey-greek` (48) and `simplex` (65, capitals, digits and folded smalls). `simplex` is its own bundled font with its original geometry, not a Hershey alias. Hershey Cyrillic is not bundled (deferred). The library never downloads a font and never reads one from the OS; user fonts arrive as bytes through `register_font`.

A font's identity is `asset:sha256:<64 hex>` of its exact file bytes. Recipes store that URI, never the short name. A name is a convenience: it points at one font at most. A font whose name already points at other bytes, such as an older release of a bundled font read from a document, is reachable by URI only. Validating a `FontRegistry` from data (`FontRegistry.from_json`) loads every font from its bytes and rejects one that differs with `FONT_HASH_MISMATCH`.

| Function or class                                                                                                                              | Inputs                                                                                                                        | Output                  | Purpose                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------- |
| `FontRegistry`                                                                                                                                 | `fonts: Mapping[uri, Font]`, `sources: Mapping[uri, bytes]`, `names: Mapping[name, uri]`; all read-only and JSON-serializable | frozen model            | Loaded fonts, their bytes and names; `resolve(ref)` turns a name or URI into a URI    |
| `bundled_fonts()`                                                                                                                              |                                                                                                                               | `FontRegistry`          | The five bundled fonts, cached and read-only                                          |
| `register_font(registry, data, *, if_name_taken="raise")`                                                                                      | bytes of a `showpy.font.v1` JSON file, at most `MAX_FONT_BYTES` (8 MiB); `if_name_taken="keep"` registers by URI only         | `(FontRegistry, uri)`   | New registry with the font added; the same registry when it already holds these bytes |
| `load_font(data)`                                                                                                                              | same bytes                                                                                                                    | `Font`                  | Validates one font; every stroke is one subpath of positive length                    |
| `layout_text(text, fonts, height, at, *, rotation=0, align="left", anchor="baseline", letter_spacing=0, line_spacing=1.2, font_registry=None)` | `fonts` is a chain of names or URIs; `align` is `left`, `center` or `right`; `anchor` is `baseline`, `middle` or `top`        | `tuple[LaidGlyph, ...]` | Glyph strokes in stage meters, in reading order                                       |

Layout rules, all measured on the first font of the chain:

- `height` is the cap height in meters, at least `MIN_LAYOUT_HEIGHT_M` (1e-3 m). `letter_spacing` and `line_spacing` are fractions of the first font's em, where `em_m = height * units_per_em / cap`.
- Each glyph is scaled so its own cap height equals `height` and advances by its own font's advance, so mixed chains stay level.
- Each character takes the first font in the chain that has it. A character that no font has raises `MISSING_GLYPH`.
- `rotation` is degrees counter-clockwise about `at`; 0 reads left to right toward +x. Glyph y-up maps to stage +y.
- Text is NFC-normalized (`e` + U+0301 becomes `é`). `\r\n`, `\r` and `\n` each start one new line. Trailing empty lines are dropped; interior ones are kept. Whitespace-only text raises a teaching `SchemaError`.
- Slot order is reading order: lines top to bottom, glyphs in logical order, strokes in font order, each stroke from its start.
  Caps are checked before anything is built:

| Cap                       | Value   | Applies to                                            | Failure                |
| ------------------------- | ------- | ----------------------------------------------------- | ---------------------- |
| `MAX_LAYOUT_CHARS`        | 1,000   | Raw characters of `text`, before normalization        | `SchemaError`          |
| `MAX_LAYOUT_EXTENT_M`     | 1e6 m   | Laid extent of the text block                         | `GeometryError`        |
| `MAX_FONT_BYTES`          | 8 MiB   | One font file                                         | `FontError` `BAD_FONT` |
| `MAX_GLYPH_PIECES`        | 512     | Path pieces of one glyph, over all its strokes        | `FontError` `BAD_FONT` |
| `MAX_STROKE_PIECES`       | 384     | Path pieces of one stroke                             | `FontError` `BAD_FONT` |
| `MAX_LAYOUT_PIECES`       | 512,000 | Path pieces of all laid glyphs of one text            | `SchemaError`          |
| `MAX_LAYOUT_CURVE_PIECES` | 60,000  | Path pieces of all laid curved strokes of one text    | `SchemaError`          |
| `MAX_TEXT_FONTS`          | 16      | Fonts in one `TextRecipe` chain                       | `SchemaError`          |
| `MAX_TEXT_SPOTS`          | 10,000  | Spots in one text form (`e8s.choreo.form_text`)       | `TOO_MANY_SPOTS`       |
| `MAX_IMPORT_FONTS`        | 64      | Fonts embedded in one document read by `import_fonts` | `FontError` `BAD_FONT` |

The glyph, stroke and layout piece caps are about 10 times the bundled maxima measured on 2026-11-16: the most complex bundled glyph, hershey-script `8`, has 51 pieces, the longest stroke, hershey-script `Z`, has 38, and 1,000 copies of the heaviest glyph lay 51,000. A curved stroke becomes an `SvgCurve`, whose table costs about 60 µs per piece to measure and place against about 1 µs for a straight one (measured 2026-11-17), so `MAX_LAYOUT_CURVE_PIECES` bounds those separately; bundled Relief needs at most 15,000 for 1,000 glyphs. `load_font` counts pieces while parsing, before sampling; `layout_text` parses each distinct glyph once and counts before building a stroke (NFC can lay out more glyphs than raw characters, for example U+0344 lays two). The worst legal text (1,000 glyphs, 512,000 pieces, 59,904 of them curved) builds a text form in about 3 s.

`text_outline` changed with this feature: it takes a font chain and `font_registry`, returns `list[Polyline | SvgCurve]`, closes glyph loops without repeating the start point, starts a new line at `\n` (it used to raise), rejects a non-finite `height` or `at`, raises `GlyphError` or `MissingFontError` (both `UnknownRefError`) for a missing glyph or font, and shares the two layout caps.

## e8s.choreo (part 1): placements, sets, forms, matching

A set is a snapshot of where every spot is; forms are the stored shapes that generate those positions; matching decides who takes which spot.

Rules:

- **No open slots.** A text form needs `len(members) == n` and no `None` member at construction and after every edit. A mismatch raises `MEMBER_COUNT_MISMATCH` with `add k more spots` or `remove k spots` in the hint. `delete_spots` may still leave a text form short; `placements` (so `place` and `rebuild`) then raises `MEMBER_COUNT_MISMATCH` before any layout, and `apply_match` raises it when a match takes a text form's member away. Both hints point at `edit_text_count`.
- **`spacing=` derives the count.** The count comes from the stroke lengths and is stored as `n`; `TextRecipe.spacing` records the request that last set the count, not the current spacing. A text edit keeps both. Lengths are measured after the form's stored `transform`, so `spacing` is stage meters; `text_spot_count` returns the count before the form exists.
- **Minimums.** Each stroke gets at least 2 spots when open and 3 when closed. A count below the sum raises `TOO_FEW_SPOTS`; after `edit(text=...)` the hint says how many spots to add with `edit_text_count`. A spacing far from letter size is clamped up to the minimums and emits `LegibilityWarning`, measured in stage meters after the stored transform.
- **Junction gap.** A stroke's spots keep `JUNCTION_GAP_SHARE` (0.25) of its spot spacing from other strokes' spots wherever some spread allows it (`e8s.choreo.text_spread`). Where none does, as with Hershey doubled or converging strokes, the stroke takes the spread whose closest spot is farthest away and `text_report(form)` lists it; nothing falls back silently. Two spots never lie within `COINCIDENT_TOL_M` (1e-6 m); if every spread would, `COINCIDENT_SLOTS` is raised.
- **Order.** Member i stands on slot i, in reading order.
- **Transforms.** `transform_form` maps slots and tangents; `along` facings turn with the text.
- **User fonts.** `match`, `cost_matrix`, `match_by_order`, `reorder`, `gate`, `split_form`, `merge_forms`, `morph_targets`, `place`, `rebuild` and `apply_match` take the keyword-only `font_registry` and pass it to every text recipe; without the font in the registry they fail closed with `MissingFontError` naming the hash. `swap` evaluates no layout and takes none. `split_form` and `merge_forms` on a text form return custom forms (the recipe is dropped). Repositories do not store fonts in the asset store yet (stage 2): a show reopened from a repository rebuilds a user-font text form only with a registry that holds the font, else `MissingFontError`, never a substitute; `export_json` and `import_fonts` carry fonts with the show today.

**Editable custom shapes.** A form can be generated by a registered function instead of a built-in shape, and stays editable by changing its parameters. Its `kind` is `generated`; its recipe is a `GeneratedRecipe{fn, params}` whose `params` are a read-only JSON object, passed to user generators as plain JSON. Built-in generators: `spiral`, `sine_wave`, `rose`; they validate their parameters through `SpiralFormParams{center, r0, r1, turns, start_deg}`, `SineWaveFormParams{start, length, amplitude, wavelength, phase_deg}` and `RoseFormParams{center, radius, petals, inner}`, so an unknown or invalid parameter raises `SchemaError` before any geometry is built. `FormFnRegistry.fns` is a read-only mapping.

## e8s.choreo (part 2): paths, engine, avoidance

Path rows are instructions for how each spot travels between two sets; the path engine is the single piece of code that turns them into exact positions, facings and states at any moment, used by every consumer, preview and exports.

Compile rules (ADR 0002): each move compiles to a curve plus a piecewise-linear time map from local count to arc length, with knots at the window ends and every timed waypoint. Position is `curve.point_at(map(ease(u)))` with u = (tau − start)/(end − start), clamped. The curve is a segment, polyline, centripetal Catmull–Rom spline, arc about the pivot, trimmed route, or sampled custom polyline. Outside its window a spot stands at the previous or next placement; `on_field` comes from the previous set before the window, the next set after it, and is the OR of both during it. Facing runs in three phases: the previous facing, then the row's `FacingMode` blended in over `turn_counts`, then the next set's facing; `FacingOverride`s win inside their range. HOLD, ROTATE, FOLLOW and CUSTOM must end within 1e-6 m of the target. `segments` subdivides time adaptively from every knot and window edge, probing every eighth of a segment until each probe is within `tol / 2`, so closest-approach checks are exact to `tol`, including crossings between counts.

`e8s.show.documents` splits a show into documents and back (`encode_show`, `decode_show`); `e8s.show.files` maps workspace paths onto them. `Workspace.show_at(revision)` returns the show at a revision, or None before the first save.

**Stored format.** `/show/show.json` opens with `"format": "e8.show"` and `"version": 2` (`FORMAT`, `CURRENT_VERSION` in `e8s.show.migrate`); a tree without the header is version 1. Every stored document is read with a strict JSON parser that refuses NaN, infinity, repeated keys, a byte-order mark and lone surrogates (`STRICT_JSON`). A v1 tree is migrated on read through one named sub-step per concern (forms, paths, selectors, timeline, facings, sheet, cast, events, then IDs); nothing stored is rewritten until the next save, which writes one normalizing revision that a v0.3.0 reader refuses. A v1 tree's design notes leave the show: the migration writes them as plain JSON to `/notes/notes.json` (`{"format": "e8.notes", "version": 1, "show": ..., "notes": [...]}`), and e8Show has no notes model, so hosts read that file themselves. Version 2 also drops the sheet's `landmarks`, `zones` and `default_coordinates`, the show's `coordinates` and `zones`, and each spot's `claimable`; `MigrationReport.dropped` lists each one whose stored value differs from its v1 default (an empty list, the default coordinate system, `"performer"`), so a host that still needs a value can keep it. A tree newer than the release raises `VersionError`, and a commit or workspace write of an older show.json raises `SchemaError` (`OLD_FORMAT`).

Stored paths address sets by key (`/sets/<key>/…`, `/transitions/<key a>-<key b>/…`, and the set order in `/show/show.json` lists keys); `Repository.read` and `paths` return stored paths. `Workspace` paths address sets by display ID and map onto keys through `e8s.show.set_keys`, so `renumber` followed by `save_show` moves no file. A workspace folder that names no set but matches another set's key, ignoring case, raises `StorageError` (code `AMBIGUOUS_PATH`). `save_show` and `revert` commit stored paths as they are. `add_set`, `insert_subset`, `import_positions` and `join_sections` give a new set the key `<id>`, or the first free `<id>.<n>` (n from 2) when a live set holds it; a key that differs from the ID must pass `check_id`, while stored IDs that predate ADR 0006 keep loading. ## Checker (consumer, planned)

Not built yet (out of scope for the first build, 2026-11-11).

A separate consumer package, run in its own process and depending on a pinned e8Show release. e8Show never imports it; it is reached only through the `run_checks` tool and hooks. It reads the show through the `Repository` and computes motion with the same `PathEngine`.

### Checker models

**Enums**: `Severity` = `ERROR`, `WARNING`, `INFO`. `CheckName` = `COLLISIONS`, `NEAR_MISSES`, `SPEED`, `TURN_RATE`, `CONTINUITY`, `INTERVAL`, `BOUNDS`, `ZONES`, `FACING` (object, behavior, contact and sightline checks are added by the 3D layer).

**`LimitsConfig`** (`/config/limits.yaml`; designer-owned, pack defaults)

| Field                                           | Type                                                                                             | Meaning                                                                                               |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `collision_gap`                                 | `Meters`                                                                                         | Gap after footprints below which two entities collide                                                 |
| `near_miss_gap`                                 | `Meters`                                                                                         | Warning threshold                                                                                     |
| `radius_by_group`                               | `Mapping[str, Meters]`                                                                           | Extra footprint by group                                                                              |
| `max_speed`                                     | `list[tuple[CountsPerMinute, float]]` or m/s                                                     | Tempo-dependent speed limit (m/count)                                                                 |
| `max_speed_backward_pct`, `max_speed_slide_pct` | `float`                                                                                          | Direction-dependent limits                                                                            |
| `reference_height_m`                            | `float`                                                                                          | Height the limits are written for                                                                     |
| `max_turn_rate`                                 | `Degrees` per count                                                                              | Facing change limit                                                                                   |
| `interval_tolerance`, `min_interval`            | `Meters`                                                                                         | Form spacing rules                                                                                    |
| `bounds`                                        | `"surface"`, `"surface+margins"`, `Polygon`                                                      | Allowed area                                                                                          |
| `zones`                                         | `list[Zone]`                                                                                     | Extra restricted areas                                                                                |
| `facing_rules`                                  | `list[FacingRule{at: SetId \| Count, entities: Selector, expect: Degrees \| str, tol: Degrees}]` | Required facings                                                                                      |
| `checks_enabled`                                | `list[CheckName]`                                                                                | Active checks                                                                                         |
| `severity`                                      | `Mapping[CheckName, Severity]`                                                                   | Error versus warning                                                                                  |

**`Finding`** — `check: CheckName, severity: Severity, tid: TransitionId \| None, set_id: SetId \| None, entities: tuple[SpotId, ...], at: float \| None, value: float \| None, limit: float \| None, message: str` (rendered as one line). **`CheckReport`** — `findings: list[Finding], summary: dict[CheckName, int], scope: str, revision: str`.

### Checker waivers (breaking rules on purpose)

A waiver records that the designer deliberately allows something the checker would flag, such as a tight weave or a crowded moment. The checker is a consumer package, so e8Show has no principals and does not decide who may record a waiver: the host application owns that rule and stores the result in `/config/waivers.yaml`, an ordinary file to e8Show.

| Data class      | Fields                                                                                                                                                                                                                                         | Represents                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `Waiver`        | `id: str, check: CheckName, entities: Selector, scope: SetId \| TransitionId, window: tuple[float, float] \| None (local counts), limit_override: float \| None, reason: str, approved_by: str, created_at: datetime, expires_on_change: bool` | An approved exception, optionally with a relaxed limit instead of a full skip |
| `WaiverRequest` | `check, entities, scope, window, limit_override, reason, requested_by`                                                                                                                                                                         | The agent asking for an exception                                             |

| Function                                                                           | Inputs          | Output            | Purpose                                              |
| ---------------------------------------------------------------------------------- | --------------- | ----------------- | ---------------------------------------------------- |
| `request_waiver(ws, request)`                                                      | `WaiverRequest` | request id        | Agent proposes; shows on the canvas for the designer |
| `approve_waiver(ws, request_id, approver)` / `deny_waiver(ws, request_id, reason)` |                 | `Waiver` / `None` | Decision, recorded by whoever the host allows        |
| `list_waivers(ws, scope=None)`                                                     |                 | `list[Waiver]`    | Current exceptions                                   |
| `revoke_waiver(ws, id)`                                                            |                 | `None`            | Remove an exception                                  |

Waived findings are reported as `WAIVED` lines with the reason instead of errors, never silently hidden. If `expires_on_change` is true, editing the waived transition voids the waiver. Contacts from `e8s.choreo.contact` are honored automatically and need no waiver. Waivers live in `/config/waivers.yaml`; e8Show enforces no write permission on it.

### Tool and hook contract

| Interface         | Input                                | Output / effect                                                                      |
| ----------------- | ------------------------------------ | ------------------------------------------------------------------------------------ |
| `run_checks` tool | `{scope, checks?, max_lines?}`       | Formatted report text; never stack traces                                            |
| After-save hook   | writes to sets, transitions, actions | Runs `scope="changed"`, appends the summary to the tool result                       |
| Before-tool hook  | any write or script                  | Denies writes to `limits.yaml` and pinned items, and scripts that import the checker |
| Stop hook         | agent tries to finish                | Blocks while error findings remain in its changes, unless waived by the designer     |

### e8s.index.models
