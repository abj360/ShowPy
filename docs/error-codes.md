# Error codes

Audience: code that handles e8Show errors and validation reports. Scope: every code a
`E8sError` raises or a `ValidationIssue` reports.

Generated by `uv run python scripts/gen_error_codes.py` from the `ErrorCode` docstrings in
`e8s/core/error_codes.py` and the raise sites in `e8s/` and `crates/`; do not edit by hand.

| Code                    | Raised by                                        | Meaning                                                                                    |
| ----------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| `ALREADY_MEMBER`        | `SchemaError`                                    | A text form edit adds a spot that is already one of the form's members.                    |
| `AMBIGUOUS_PATH`        | `StorageError`                                   | A workspace path names a set folder that matches the folder of a different set.            |
| `AUDIO_DUPLICATE`       | `ValidationIssue`                                | Two audio tracks of a timeline share one label.                                            |
| `AUDIO_RANGE`           | `ValidationIssue`                                | An audio track's section is not a (start, end) range inside the show.                      |
| `BAD_FONT`              | `FontError`                                      | A font file is not a valid font or breaks a font cap.                                      |
| `BAD_ID`                | `SchemaError`, `StorageError`, `ValidationIssue` | A repository id is not 64-digit hex, or a show, set, note or form ID cannot be stored.     |
| `BAD_PATH`              | `StorageError`                                   | A show id, workspace path or upgrade folder cannot be used, or names a folder for a file.  |
| `BAD_SHAPE`             | `GeometryError`                                  | A similarity fit gets point arrays that are not matched (N, 2) arrays of numbers.          |
| `COINCIDENT_SLOTS`      | `GeometryError`                                  | Every spread of a text stroke's spots would put two of them within 1 µm.                   |
| `CONFLICT`              | `ConflictError`                                  | A write was based on a revision that another write has since replaced.                     |
| `CONTINUITY`            | `ContinuityError`, `ValidationIssue`             | A path does not end on its target placement.                                               |
| `CORE_PANIC`            | `E8sError`                                       | A compiled core function panicked; the panic is a bug in e8s, caught at the boundary.      |
| `CORRUPT`               | `StorageError`                                   | A stored repository is damaged or is missing a blob it refers to.                          |
| `COUNTS_MISMATCH`       | `ValidationReport`                               | A transition's paths span a different number of counts than its target set.                |
| `CUE_DUPLICATE`         | `ValidationIssue`                                | Two cues of a timeline share one label.                                                    |
| `CUE_NEGATIVE`          | `ValidationIssue`                                | A cue's estimated duration is negative.                                                    |
| `DEGENERATE`            | `GeometryError`                                  | The landmarks of a similarity fit sit on top of each other.                                |
| `FONT_HASH_MISMATCH`    | `FontError`                                      | Font bytes do not hash to the URI or pinned hash that names them.                          |
| `FONT_NAME_TAKEN`       | `FontError`                                      | A font registers under a name that is already bound to different font bytes.               |
| `GEOMETRY`              | `GeometryError`                                  | A shape is degenerate, such as a zero radius or collinear arc points.                      |
| `HOLD_NEGATIVE`         | `ValidationIssue`                                | A hold sits before count 0 or lasts a negative number of counts.                           |
| `HOLD_OVERLAP`          | `TimelineError`, `ValidationIssue`               | Two holds of a timeline share one count.                                                   |
| `IO`                    | `StorageError`                                   | The file system fails while a file repository reads or writes.                             |
| `KEY_MISMATCH`          | `ValidationIssue`                                | A mapping key differs from the ID of the item it holds.                                    |
| `LOCKED`                | `LockedError`                                    | An edit touches a pinned or locked item without `force=True`.                              |
| `MARKER_DUPLICATE`      | `ValidationIssue`                                | Two markers of a timeline share one label.                                                 |
| `MARKER_RANGE`          | `ValidationIssue`                                | A marker falls outside the show's counts.                                                  |
| `MATCH`                 | `MatchError`                                     | An assignment of spots to slots has no feasible solution.                                  |
| `MEASURE_LENGTH`        | `TimelineError`, `ValidationIssue`               | A measure length is not positive or a measure change count is negative.                    |
| `MEMBER_COUNT_MISMATCH` | `SpacingError`                                   | A text form has a different number of members than slots.                                  |
| `MEMBER_MISMATCH`       | `ValidationIssue`                                | A form lists a spot as a member, but that spot's placement does not name the form.         |
| `MISSING_EXTRA`         | `MissingExtraError`                              | A function needs an optional dependency whose e8s extra is not installed.                  |
| `MISSING_FONT`          | `MissingFontError`                               | A font name or URI is not held by the font registry.                                       |
| `MISSING_GLYPH`         | `GlyphError`                                     | No font in the chain has a glyph for a character of the text.                              |
| `MISSING_SPOT`          |                                                  | A spot of the cast has no placement in a set.                                              |
| `MIXED_OPERATORS`       | `SchemaError`                                    | A selector mixes `&` with `+` or `-` at one parenthesis level without parentheses.         |
| `NAME_TAKEN`            | `ConflictError`, `SchemaError`                   | A named selection or a proposal is created under a name that is already taken.             |
| `NAME_TOO_LONG`         | `StorageError`                                   | A file repository path is longer than the file system allows.                              |
| `NOT_A_MEMBER`          | `SchemaError`                                    | A text form edit removes a spot that is not one of the form's members.                     |
| `NOT_A_TEXT_FORM`       | `SchemaError`                                    | A text-only operation gets a form of another kind.                                         |
| `NOT_CONFIRMED`         | `StorageError`                                   | A repository repair lacks confirm=True or the caller's time `at`, or confirm lacks repair. |
| `NOT_FINITE`            | `GeometryError`, `ValidationIssue`               | A similarity fit or a stored show field holds a NaN or infinite number.                    |
| `NOT_IN_FORM`           |                                                  | A placement names a form it is not a member of in that set.                                |
| `NOT_SERIALIZABLE`      | `SchemaError`                                    | A model that is never stored, such as a registry of functions, goes to or from JSON.       |
| `NO_HARDLINKS`          | `StorageError`                                   | The file system under a file repository cannot create hard links.                          |
| `N_OR_SPACING`          | `SchemaError`                                    | A text form request gives both or neither of `n` and `spacing`.                            |
| `OLD_FORMAT`            | `SchemaError`                                    | A write would store a show.json of an older format version than this release writes.       |
| `OLD_LAYOUT`            | `VersionError`                                   | A write targets a layout-1 repository, which this release only reads until it is upgraded. |
| `PATH`                  | `PathError`                                      | A path instruction is invalid.                                                             |
| `PINNED_CHANGED`        |                                                  | An edit changes a pinned placement.                                                        |
| `PROPOSAL_CLOSED`       | `SchemaError`                                    | A proposal that is already accepted, rejected or withdrawn is changed again.               |
| `PROPOSAL_STALE`        | `ConflictError`                                  | An open proposal touches items that changed since its base revision, so it is not applied. |
| `RAMP_CUT`              | `ValidationIssue`                                | A tempo ramp is cut short by the next tempo section.                                       |
| `RAMP_INCOMPLETE`       | `ValidationIssue`                                | A tempo ramp sets only one of `ramp_to` and `ramp_counts`.                                 |
| `RAMP_LENGTH`           | `ValidationIssue`                                | A tempo ramp lasts no counts.                                                              |
| `RANGE_PADDING`         | `SchemaError`                                    | A range's endpoints are spelled with different zero-padding, such as `T1-T010`.            |
| `READ_ONLY`             | `LockedError`                                    | A write targets a derived workspace file, which is read-only.                              |
| `REFLECTION`            | `GeometryError`                                  | The landmarks of a similarity fit are mirrored between the two sheets.                     |
| `RESERVED_MOTION`       | `PathError`                                      | A motion registry would bind a built-in motion name to another function.                   |
| `SCHEMA`                | `SchemaError`                                    | Data fails its schema or text format.                                                      |
| `SEGMENT_BOUND`         | `PathError`                                      | A compiled path segment strays further from its motion than the engine allows.             |
| `SHOW_TOO_LONG`         | `ValidationIssue`                                | The show's total counts exceed MAX_COUNTS.                                                 |
| `SPACING`               | `SpacingError`                                   | Items do not fit in the space or count given.                                              |
| `STAGE`                 | `E8sError`                                       | A library failure that no more specific code describes.                                    |
| `STALE_FORM`            | `E8sError`                                       | A form's set no longer places that form.                                                   |
| `STALE_TRANSITION`      |                                                  | A transition holds paths for two sets that are not consecutive.                            |
| `STORAGE`               | `StorageError`                                   | A show cannot be persisted or read back.                                                   |
| `STRICT_JSON`           | `SchemaError`                                    | Stored or imported JSON holds NaN, infinity, a repeated key, a BOM or a lone surrogate.    |
| `SURFACE`               | `SurfaceError`                                   | A point is off the sheet.                                                                  |
| `TEMPO_MISSING`         | `ValidationIssue`                                | A timeline in counts mode has no tempo.                                                    |
| `TEMPO_NONPOSITIVE`     | `ValidationIssue`                                | A tempo section's tempo is not positive.                                                   |
| `TEMPO_ORDER`           | `ValidationIssue`                                | Tempo sections are not in increasing count order, one per count.                           |
| `TEMPO_START`           | `ValidationIssue`                                | The first tempo section does not start at count 0.                                         |
| `TEXT_COUNT_EDIT`       | `SchemaError`                                    | `edit` is asked to change a text form's spot count, which only `edit_text_count` does.     |
| `TIMELINE`              | `TimelineError`                                  | Tempo, measure or hold data is inconsistent.                                               |
| `TIME_RANGE`            | `TimeRangeError`                                 | A time is outside its range, or a start is not before its end.                             |
| `TOO_FEW_POINTS`        | `GeometryError`                                  | A similarity fit gets fewer than two matched points.                                       |
| `TOO_FEW_SPOTS`         | `SpacingError`                                   | A form or text asks for fewer spots than its curves or strokes need.                       |
| `TOO_LARGE`             | `StorageError`                                   | A repository file, or the history of a show, is over its size cap.                         |
| `TOO_MANY_SETS`         | `SchemaError`                                    | A show holds more sets than MAX_SETS.                                                      |
| `TOO_MANY_SPOTS`        | `SchemaError`, `SpacingError`                    | A cast holds more spots than MAX_SPOTS, or a text form asks for more than its own cap.     |
| `TORN_SLOT`             | `StorageError`                                   | A repository slot stays empty or cut short after every reread: its writer stopped early.   |
| `UNKNOWN_FORM`          | `ValidationIssue`                                | A placement names a form that does not exist.                                              |
| `UNKNOWN_FORMAT`        | `SchemaError`                                    | A show.json or interchange document names no known format, or half a format header.        |
| `UNKNOWN_REF`           | `UnknownRefError`                                | An ID, name or unit does not resolve.                                                      |
| `UNKNOWN_SET`           | `ValidationIssue`                                | A form names a set that is not in the show.                                                |
| `UNKNOWN_SHEET`         | `ValidationReport`                               | The show's sheet reference does not resolve in the sheet store.                            |
| `UNKNOWN_SPOT`          | `ValidationIssue`                                | A set, transition, route or named selection names a spot that is not in the cast.          |
| `UNPINNED_SHEET`        | `ValidationReport`                               | The show's dependencies do not pin its sheet reference.                                    |
| `VALIDATION`            | `ShowValidationError`                            | A structural integrity check fails.                                                        |
| `VERSION`               | `VersionError`                                   | A pinned version is missing or incompatible, or a stored show is newer than this release.  |
| `ZERO_COUNTS`           |                                                  | A set after the first arrives in 0 counts.                                                 |
| `ZERO_LENGTH`           | `ZeroLengthError`                                | The direction of a zero vector is requested.                                               |
