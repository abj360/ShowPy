## Unreleased

### BREAKING CHANGES

- `FrozenModel` constructors, `model_validate` and `model_validate_json` raise `SchemaError` instead of `pydantic.ValidationError`; `SchemaError` is not a `ValueError`, so `except ValueError` no longer catches invalid model data. (b1e12ed)
- `FrozenModel` rejects NaN and infinity in every float field, so v0.2.0 documents that hold `NaN` or `Infinity` no longer decode; they raise `SchemaError`. (ea9832c)
- every `content_hash` value changes once; stored revision IDs are kept. (14a3dea)
- `Spot.tags` and `Cast.selections` hold ordered tuples instead of frozensets; compare with tuples and do not rely on set methods. (e6a8d79)
- `add_spot`, `add_spots_along`, `fill_spots` and `duplicate_spots` gain keyword-only `force`; `delete_spots(force=True)` drops pins on deleted spots. (3a83299)
- `split` raises SchemaError when k exceeds the selection size; adds `split_id`. (2266c13)
- `delete_spots` takes `force` as a keyword-only argument. (5fa40ba)
- `replace_sheet` and `SheetReplaceReport` are removed from the public API. (f6f8e9c)
- `place` returns `(Set, list[Form])`; unpack the set and store the filled forms. (b186052)
- `publish` requires a join token on the first publish and accepts only https `base_url` values without query, fragment or credentials. New public name `verify_join_token`; `Publication` gains the optional `join_token_sha256`. The stored link carries no token since ADR 0018, and `join_link` adds it. (aab609c)
- `Claim` drops performer contacts on load and construction; `claim_spot`, `claims`, `who_is_on`, `notify_changes` and `performer_view` return contact-free performers. Hosts keep contacts in their own roster keyed by `Performer.id`. (9958599)
- `to_csv` now writes a leading quote on text cells that start with a formula trigger, and takes a keyword-only `neutralize` flag. Pass neutralize=False to read cells back unchanged. (f94ccc7)
- `Publication.link` no longer carries the join token; a stored E1-era link loses its `t` query parameter on load and keeps its digest. New public name `join_link(pub, token)` verifies the token in constant time and returns the joinable link `<link>?t=<token>`. `qr_code(pub, token, size=512)` takes the token and encodes `join_link`. `publish` takes `join_token=None`, which is required on the first publish, kept from `previous` when omitted on a republish, and rotated when given. (77f1216)
